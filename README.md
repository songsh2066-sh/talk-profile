# 발표용 프로필 사이트 (서울시립대 실전 AI 과정 · 2026.11.27)

15분 발표 구성표(11/25 개편: 1·3·7·1·3분) 순서대로 넘기는 프로필 사이트입니다. 기존 프로필(https://web-resume-bice.vercel.app)은 그대로 두고, 이 저장소를 새 Vercel 프로젝트로 따로 배포합니다.

| 순서 | 주소 | 내용 | 시간 |
|---|---|---|---|
| 01 | `/` | 홈 · 자기소개 · 오늘 발표 순서 | 1분 |
| 02 | `/midterm` | 중간평가 · 서울 메이트 (네 가지 방식 비교표, 대시보드 열기) | 3분 |
| 03 | `/erlink` | 메인 프로젝트 · ERLink AI (문제 → 흐름 → 라이브 시연 → 내가 만든 것 → 피드백·결과, 예비 캡처) | 7분 |
| 04 | `/extra` | 추가 프로젝트 | 1분 |
| 05 | `/results` | 성과 · 마무리 | 3분 |

- 발표 중 키보드 `→` `←` (또는 PageDown·PageUp)로 다음·이전 페이지
- 순서·시간·링크는 `data/talk.ts` 한 곳에서 바꿉니다
- ERLink 시연 버튼은 https://erlink.songsh.cloud 로 열립니다 (발표 노트북의 ERLink 를 Cloudflare Tunnel 로 연결 — 노트북에서 실행 중일 때만). 상단 메뉴에는 배정 시간을 표시하지 않고, 페이지 안 블록마다 시간(.cue)만 둡니다
- 발표 대본이 따로 없으므로 페이지의 굵은 글 = 말할 핵심, 작은 글 = 덧붙일 설명
- 디자인: 기존 프로필의 "근거 노트" 토큰(색·글꼴)을 그대로 씀 — `app/globals.css`
- 검색 노출 안 함 (`robots: noindex`)

## 실행 (내 PC)

```powershell
npm install        # 의존성 설치 (처음 한 번)
npm run dev        # 개발 서버 http://localhost:3001 (ERLink 가 3000 을 쓰므로 3001)
npm run build      # 배포 전 빌드 확인
```
